# Run test

## Setup
Run two different PHP Development Serves at these locations:

/api - run this server at :8000

/api/test - run this server at any port OTHER than :8000

## See test
Visit http://localhost:[port]/ in your browser (where [port] is the port you started the server on in the /api/test folder)
Test will run on load

### NOTE
The test automatically resets DB after you run it, so no need to be worried about ruining anything :)
